# Prediction of Water Quality Index and Contamination Risk Using Machine Learning Techniques

## Overview
This project aims to develop a machine learning framework for predicting the Water Quality Index (WQI) and classifying water contamination risk using river water-quality data from the Malaysian Department of Environment (DOE).

## Project Objectives
- Analyse and preprocess river water-quality data.
- Develop and evaluate machine learning models for WQI prediction.
- Classify contamination risk based on the defined target categories.
- Develop a dashboard to present prediction results and water-quality information.

## Study Data
The preliminary dataset currently available contains records for:
- Sungai Klang
- Sungai Skudai

The available workbook covers 2023–2024. The final dataset scope remains subject to confirmation of additional data availability from DOE.

## Technology Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook or VS Code

## Project Structure
- `data/`: Local datasets (not committed to Git)
- `outputs/`: Generated reports and charts (not committed to Git)
